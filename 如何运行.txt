===========================================
OllamaChat 模组 - 运行说明
===========================================

当前状态：
---------
✓ Gradle Wrapper 已修复
✓ Java 17 配置正确
✓ 项目配置完整

⚠ 间歇性网络问题：
   java.net.SocketException: Invalid argument: socket
   
   这是 Windows 系统级的网络问题，会导致 Gradle 无法启动。
   这个问题有时会出现，有时会消失。

解决方案（按推荐顺序尝试）：
-----------------------------

【方法 1】重启计算机（最有效！）
   这是解决此问题最简单有效的方法。
   很多用户反馈重启后问题就消失了。

【方法 2】重置 Windows 网络栈
   1. 以管理员身份打开 PowerShell
   2. 运行以下命令：
      netsh winsock reset
      netsh int ip reset
      ipconfig /flushdns
   3. 重启计算机
   4. 重新尝试运行项目

【方法 3】多次尝试
   由于这个问题是间歇性的，有时多次运行命令就能成功。
   可以连续运行几次：
   .\gradlew.bat runClient

【方法 4】禁用 IPv6
   1. 打开"控制面板" → "网络和共享中心"
   2. 点击"更改适配器设置"
   3. 右键点击当前使用的网络连接 → 属性
   4. 取消勾选"Internet 协议版本 6 (TCP/IPv6)"
   5. 点击"确定"
   6. 重新尝试运行项目

【方法 5】检查防火墙和安全软件
   1. 临时禁用第三方防火墙
   2. 临时禁用杀毒软件
   3. 将 Java 添加到 Windows 防火墙白名单
   4. 重新尝试运行项目

运行项目：
---------
问题消失后，在项目目录中运行：

.\gradlew.bat runClient

或者：

.\runclient.bat

首次运行可能需要几分钟下载资源。

游戏内使用：
-----------
启动 Minecraft 后：
- /ollama list - 列出所有模型
- /ollama model <模型名> - 切换模型
- /ollama serve - 启动 Ollama 服务
- 发送 ai <消息> 与 AI 对话

前置要求：
---------
1. Java 17（已安装在 C:\Program Files\Java\jdk-17）
2. Ollama（需要先安装并运行 ollama serve）
3. 至少一个 Ollama 模型（如 llama3）

重要提示：
---------
- 如果看到网络 socket 错误，请先重启计算机
- 这个问题不是代码问题，是系统网络配置问题
- 重启后通常就能正常运行

如果重启后仍然遇到问题：
-------------------------
这个问题是 Windows 11 上已知的网络栈问题，特别是在使用 Java 17 时。
建议的永久解决方案：

1. 以管理员身份运行 PowerShell，执行：
   netsh winsock reset
   netsh int ip reset
   ipconfig /flushdns
   然后重启计算机

2. 如果上述方法无效，可以考虑：
   - 更新 Windows 到最新版本
   - 更新网络适配器驱动程序
   - 或者在另一台计算机上运行此项目
